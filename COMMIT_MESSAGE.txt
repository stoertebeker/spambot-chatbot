## Funktionale Änderungen

### Von Bot zu Userbot
- **Vorher**: Separater Bot-Account, Spammer müssen Bot anschreiben
- **Jetzt**: Läuft mit User-Account, antwortet in User's Namen

### Neue Features
- Chat-Import: Automatisches Lernen des Schreibstils aus Historie
- Session-Persistenz: Kein Login bei jedem Start nötig
- Whitelist-System: Nur auf ausgewählte User antworten
- Pause/Resume: Schnelles Deaktivieren der Auto-Antworten

### Neue Commands (an Saved Messages senden)
- /import <user_id> - Chat-Historie importieren
- /whitelist_add <user_id> - User zur Whitelist hinzufügen
- /whitelist_remove <user_id> - User entfernen
- /whitelist_list - Alle whitelisted User anzeigen
- /pause - Auto-Antworten pausieren
- /resume - Fortsetzen
- /status - Bot-Status
- /help - Hilfe

### Environment Variables
- TELEGRAM_BOT_TOKEN → TELEGRAM_API_ID (NEU)
- ADMIN_USER_ID → Entfernt
- TELEGRAM_API_HASH (NEU)
